# 可选扩展边界

本文件定义接入位置，不启用高级能力，也不要求创建额外角色。

## 记忆

在规划或实现需要历史依据时，接收：当前问题、适用范围、候选历史记录。返回：结论、实际读取的来源、版本、适用条件与冲突/缺口。索引只导航，摘要不能替代影响决策的正文证据。历史记录不覆盖当前确认需求。

在成果通过验证后，可返回经验建议：结论、原因、适用范围、来源与被替代项。worker 默认只提交建议；只有项目明确启用并授权经验维护时，由指定单一写入者保存。没有新经验就不写。不把每项完成记录复制成记忆，不把一次成功提升为无条件规则。

可从普通 Markdown 文件开始；索引、全文搜索、外部检索是可替换实现。不可用时保留真实缺口；只有依赖该信息的决定才暂停。项目印象独立于技术经验，不随技术沉淀膨胀。

## 调度

候选输入为依赖、读写范围、资源约束和已验证的完成证据；输出为可运行任务及执行位置。调度扩展不改变任务身份、需求授权、账本写入权、审核和完成标准。

核心默认串行。并行需宿主子 agent 和隔离能力，以及可证明独立的任务；缺任一条件则串行。目录池、队列优化和远端执行可替换，不作为基础安装依赖。

重试需要新的证据或明确修正措施。重复相同失败且没有新信息时停止受影响任务。若用户配置投入或尝试限制则遵守；不能自动虚构预算，也不内置固定失败率公式。

扩展只能返回建议或证据，不能自行确认需求、标记完成、写共享账本或获得远端操作授权。未来新增扩展需声明输入、输出、可选依赖、失败回退与写入所有者。
